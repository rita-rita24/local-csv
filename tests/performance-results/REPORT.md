# LocalCSV 読み込み高速化の実測報告

## ① 実施結果

配布対象の `local-csv.html` に改善を実装し、`index.html` のダウンロード用HTMLも同一内容に反映した。実ファイルの一覧表示は100,000行で **71.4%短縮**、長いセルで **91.4%短縮**。操作可能になるまでの時間もそれぞれ **66.4%・87.0%短縮**した。引用符を省ける通常セルでも、大規模ファイルの一覧表示 **69.1%**、長いセルの一覧表示 **84.3%** の短縮を確認した。これは下記のローカル比較であり、本番サイトの改善率ではない。

**HTMLへ反映済み／公開本番サイトは未反映・未検証／本番の全画面は未計測。** ユーザー回答は「HTMLが対象です」。リポジトリは単一HTMLを直接開く配布形態で、本番URL・配信先・アップロード手順が記録されていない。GitHubの確認では `rita-rita24/local-csv` の既定ブランチは `main`、Pages無効・homepageなし。共有フォルダ等の既存配布先も特定できないため、外部配布先の差し替え・Git pushは行っていない。公開先へ反映する場合に必要なのは、URLまたは配布先と、その既存リリース手順。追加承認が原因で停止した工程はない。

- 対象URL: 本番URL **未特定**。ローカル計測はテスト専用 `http://127.0.0.1:<ランダムポート>/index.html` と `/local-csv.html`。直接ファイル起動の動作確認も実施。

### 環境・データ・キャッシュ

Node v22.22.2、Playwright経由のmacOS arm64 / Chrome 154.0.8037.99、ja-JP、1440×900、headless、同一ホスト。通常のプロファイルや保存CSVは使用せず、独立した一時コンテキストで生成データだけを使用した。通信はループバック・制限なし。本番通信や実利用者のデータには負荷をかけていない。CPU温度・OSのバックグラウンド負荷・GCの状態は制御できない。遅いケースは範囲と全サンプルに記録したが、実利用RUM・本番p95は存在せず算出していない。

主な代表データは全値を引用したUTF-8/BOMなし/カンマ/CRLFのCSV、ヘッダーなし。行・列番号を値に含め、列0はユニーク、最初のセルはtarget、列1は17行ごとに引用内CRLFを含む。小規模100×8（16,057 bytes）は通常操作、大規模100,000×20（46,913,099 bytes）は多数行・列と大量保存チャンク、長いセル2,000×3（24,059,379 bytes、各セル約4,000文字）は行数だけでは表せない入力長の差を代表する。補足として同じ値・行列数で通常セルの引用符を省き、改行のある値だけ引用したCSVも各5回比較した（UNQUOTED=1）。サイズは14,469／42,924,865／24,047,615 bytes。シナリオ生成式と正確な値は計測スクリプトに保存した。権限やユーザー間のサーバー共有はなく、保存領域はブラウザのオリジンに従う。

実ファイルは選択前にディスクへ書いた生成ファイル。OSページキャッシュを消していないため、ディスク初回のコールド読込ではない。ブラウザHTTPキャッシュ有効の比較は前後各5回、全5回の再アクセスで資源のキャッシュヒットを監査した。それ以外はCDP Network.setCacheDisabledで無効。保存復元は同じコンテキストで自動保存完了後のreload、IndexedDBは存在する状態。サーバー内キャッシュ／CDNなし。ブラウザのJSコードキャッシュやOSファイルキャッシュの完全消去は保証しない。

最初の計測にはfaviconへのPlaywright routingを使用し、HTTPキャッシュが無効化され通信割り込みの影響もあった。これに気づいた後、割り込みを除去して変更前スナップショットと最終版を同じCDP方式で取り直した。旧 `before.json` / `after.json` / `before-screens.json` / `after-screens.json` / `before-restore.json` / `after-restore.json` は診断記録として保持し、最終短縮率に使っていない。`candidate-batch.json` も試作評価用。`before-final-screens.json` / `final-screens.json` は訂正後の小規模パネル計測で、全データ量の比較は後続のall-panelsを採用した。変更前の再計測は保存した着手時HTMLを使用し、最終版と混同していない。
