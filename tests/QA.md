`npm test` は Node.js の標準機能だけで実行できます。ブラウザテストは、テスト環境に Playwright と対応するブラウザが必要です。アプリ本体にはビルド工程や依存パッケージを追加していません。

## 検証の境界

- WebKitの自動試験は実機Safariそのものではありません。Windows・モバイル・旧バージョンのブラウザ・OSネイティブの保存ダイアログは、この自動試験の対象外です。
- OSの強制終了、電源断、ブラウザによる保存領域の削除、ディスク全体の故障は再現していません。自動保存は元ファイルの更新や外部バックアップを代替しません。
- Web Locks 非対応環境ではタブ間の完全な排他を保証しません。今回の3エンジンの試験ではWeb Locksが有効です。
- 同時編集の自動マージは行いません。別タブが先に保存した場合、古いタブは既存の保存失敗表示となり、画面上のデータを保持します。
- 正規表現は2秒で中断します。正しい式でも大規模データで上限に達する場合があります。表の内容は変更せず、既存の検索エラー表示へ戻します。
- 24時間以上の連続運用、100万行以上、巨大な単一セル、全ブラウザ版・全入力形式の組合せを網羅した試験ではありません。
